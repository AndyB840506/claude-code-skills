# Banco de Temas — BTQ (Behind The Queue)

Fuente: `C:\Users\andre\repos\kit-skill-creator\btq-production\roadmap-btq.md` (repo
`kit-skill-creator`, no un repo aparte). BTQ es el podcast de liderazgo del usuario
para gerentes/supervisores de call center (~40 años, Colombia 70% + EE.UU. 20%). Cada
episodio ya trae un tema investigado, 2-3 casos reales nombrados con fuente primaria, y
un cierre "Aplicable Hoy" con acciones concretas — justo el tipo de sustancia que pide
`docs/anti-patrones-ia.md` (patrón #8: datos concretos).

**Cómo usar este banco:** solo cuando el usuario no tenga tema y lo pida. Ofrecer 2-3
ángulos de aquí, reescritos en primera persona y en formato LinkedIn — **nunca copiar
frases del guion del podcast**, es una fuente de tema y caso, no de texto. Generalizar
el ángulo de call center a liderazgo empresarial cuando aplique.

**Antes de usar un episodio como fuente:** confirmar su estado real abriendo
`pipeline-state-epXX.md` o el roadmap — esta lista se escribió el 2026-09-04 y se
desactualiza igual que el roadmap que resume.
